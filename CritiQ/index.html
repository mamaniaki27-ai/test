Project Overview

CritiQ is revolutionizing the insurance landscape with Starknet-Indemnify, an on-chain, parametric-first insurance platform built on Starknet. Our mission is to deliver fast, fair, and fully on-chain insurance solutions, starting with Flight Delay, Smart Contract Risk, and Commercial Property coverage, with plans to expand as oracle infrastructure evolves.

Key Features

- Instant or near-instant payouts triggered by verifiable events
- Multi-oracle consensus for secure, fraud-resistant automation
- Transparent audit trails with sensitive data protected yet provably unaltered
